# Kikitori

録音と文字起こしをする macOS のメニューバーアプリです。文字起こしは whisper.cpp を使い、すべてこの Mac の中で処理します(ネット接続・API料金は不要)。

## 使い方

| 操作 | ショートカット(設定で変更可) | メニュー |
|---|---|---|
| 録音を開始 / 終了して文字起こし | ⌃⌥⌘R | 録音を開始 / 終了して文字起こし |
| 一時停止 / 再開 | ⌃⌥⌘P | 一時停止 / 再開 |
| 録音を破棄 | ⌃⌥⌘⌫ | 破棄してゴミ箱へ |
| 録音状態を確認(押している間だけ表示) | ⌃⌥⌘I | — |

- 終了すると自動で文字起こしが始まり、終わったら通知が出ます
- 一時停止していた間の音は録音されません(タイムスタンプも一時停止を除いた時間になります)
- 破棄した録音は macOS のゴミ箱に移るので、間違えても元に戻せます
- ⌃⌥⌘I を押している間、画面上部に「録音中 / 一時停止中 / 待機中」、経過時間、マイクとPCの音の音量メーターが出ます。メーターが動いていれば音が録れています。音が届いていないときは警告が出ます。アイコン非表示モードでも使えます(画面共有には映らない設定ですが、共有アプリによっては映る場合があります)
- 保存先: `~/Documents/Kikitori/<日時>/`
  - `<日時>.txt` … `[00:01:23] 発言` の形式。タイムスタンプ付きの文字起こし
  - `<日時>.srt` … 字幕形式
  - `<日時>.m4a` … 聞き返し用の音声。マイクとPCの音を1本にまとめた圧縮音声(設定でオフにできます)
  - `<日時>_mic.flac` / `<日時>_system.flac` … 元の音声。マイクとPCの音を別々に、元の音質(48kHz・16bit、PCの音はステレオ)のまま保存。2本の開始位置は揃えてあります(設定でオフにできます)

## 設定項目

| 項目 | 内容 |
|---|---|
| 録音ソース | マイクのみ / PCの音のみ / マイク + PCの音 |
| ショートカット | 開始・終了 / 一時停止 / 破棄 / 状態確認 のそれぞれに設定。ボタンを押してから、登録したいキーの組み合わせを押す(⌃⌥⌘ のいずれかが必須)。開始・終了以外は解除もできる |
| 録音中の表示 | 赤アイコンと経過時間を表示 / アイコンを変えない / メニューバーにアイコンを出さない |
| 効果音・通知 | 開始・停止時の効果音、完了通知をそれぞれ ON/OFF |
| 文字起こし | 言語、語彙ヒント(固有名詞など)、クリップボードへのコピー |
| 保存先 | 保存フォルダ、聞き返し用の音声 (.m4a) と元の音声 (.flac) をそれぞれ残すかどうか |

アイコン非表示モードのときは、Finder や Spotlight から Kikitori をもう一度開くと設定画面が出ます。

## 必要な権限

- **マイク**: 初めて録音するときに確認ダイアログが出ます
- **画面収録とシステムオーディオ録音**: PCの音を録るときに必要です。システム設定 > プライバシーとセキュリティ で許可したあと、アプリを再起動してください

## ビルド

```sh
./build.sh          # build/Kikitori.app を作成
./build.sh install  # ~/Applications にインストールして起動
```

必要なもの: `brew install ffmpeg whisper-cpp`、モデル `~/.cache/whisper-cpp/ggml-large-v3-turbo.bin`
(任意で VAD モデル `~/.cache/whisper-cpp/ggml-silero-v5.1.2.bin` があると、無音部分での誤認識が減ります)

ローカルで署名しているため、再ビルドすると macOS の権限許可がリセットされることがあります。その場合はもう一度許可してください。

### 動作確認用のコマンド

```sh
build/Kikitori.app/Contents/MacOS/Kikitori --render-hud <フォルダ>       # 状態確認の表示をPNGで書き出す
build/Kikitori.app/Contents/MacOS/Kikitori --render-settings <フォルダ>  # 設定画面の各ページをPNGで書き出す
```

### 文字起こしだけを試す

```sh
build/Kikitori.app/Contents/MacOS/Kikitori --transcribe 音声ファイル.m4a
# 2本渡すとマイク + PCの音として扱う (2本目は1.5秒遅れて始まったものとして時刻合わせを確認できる)
build/Kikitori.app/Contents/MacOS/Kikitori --transcribe mic.caf system.caf
```
